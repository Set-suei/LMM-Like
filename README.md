# LLM赞我（astrbot_plugin_LLM_like）

LLM点赞插件，可以在赞我的同时调用LLM说话，支持大模型自主考虑给不给点赞、任意方式要赞识别与原生函数调用（Tool Calling）。

## 特性
- **LLM 考虑给不给点赞**：在 @Bot 前提下，无论用户是发送“赞我”指令还是以任意自然语言方式求赞，均可由大模型结合当前人设性格、心情、上下文互动记录与对方态度，自主决定是否给赞（或傲娇拒绝、提出条件后再给赞）；
- **全方式要赞支持**：所有要赞方式均以 @Bot 为触发前提（未 @Bot 绝不触发），支持 @Bot 后发送指令、口令、带标点/表情的花式求赞，以及通过全局对话钩子（`on_llm_request` / `on_llm_response`）与原生函数调用（`send_qq_like`）联动，只要 @Bot 后以任何方式要赞都可以给；
- **人设反应与性格台词**：自动读取当前会话的人格设定（Persona Prompt），由大模型根据点赞结果或决策理由实时生成符合人设的个性化台词；
- **语音插件深度适配**：深度联动 genie 语音合成插件（TTS），遵循会话双语开关，自动生成日文语音协同播报；
- **冷却防刷与并发保护**：内置用户冷却时间与异步并发锁，防止频繁连续刷屏。

## 指令与用法说明
- **直接或花式求赞（需 @Bot）**：发送 `@Bot 赞我`、`@Bot 赞我？`、`@Bot 给我主页点个赞`、`@Bot 可以给我主页点赞吗`、`@Bot 为什么不赞我呢` 等任意求赞表达，Bot 将结合人设考虑是否给赞并回应（未 @Bot 不会触发）；
- **拒绝后互动追赞**：若 Bot 傲娇拒绝并提出条件（如要求夸奖或改口称呼），用户后续回应兑现条件时，Bot 会结合短期互动记忆继续判断是否给赞；
- **常规对话联动 & 函数调用**：在接入 group_chat_plus 或原生会话的日常闲聊中，用户以任何委婉暗示或创意方式要赞，LLM 均可通过 `[ACTION:LIKE]` 标记或调用 `send_qq_like` 工具完成点赞。
