# LLM赞我 (astrbot_plugin_qq_like)

LLM点赞插件，可以在赞我的同时调用LLM说话，支持大模型自主决策点赞与原生函数调用（Tool Calling）。

## 特性
- **自主意图识别与决策**：支持自然语言问询（如“小千岁会给我点赞吗”、“能帮我点个赞吗”等），由大模型根据当前人设性格、好感度与对话语境自主判断是否给对方点赞；
- **原生函数调用 (LLM Tool)**：向 AstrBot 注册 `send_qq_like` 原生工具，无缝适配群聊增强插件与主 Agent 函数调用生态，支持 Bot 在日常闲聊中自主决策调用；
- **双模触发机制**：既支持指令秒赞（发送“赞我”、“/赞我”、“点赞”等直接拉满上限），也支持自然拟人化互动决策；
- **人设反应与性格台词**：自动读取当前会话的人格设定（Persona Prompt），由大模型根据点赞结果或决策理由实时生成符合人设的个性化台词；
- **语音插件深度适配**：深度联动 genie 语音合成插件（TTS），遵循会话双语开关，自动生成日文语音协同播报；
- **冷却防刷与并发保护**：内置用户冷却时间与异步并发锁，防止频繁连续刷屏。

## 指令与用法说明
- **指令触发**：发送 赞我、/赞我、点赞、点名片赞、like，直接为发送者（或 @ 的群友）刷满当日名片赞；
- **自然问询触发**：发送自然提问（例如“小千岁会给我点赞吗”、“能帮我点赞吗”等），Bot 将结合当前人设与态度自主决定是否点赞并做出对应口吻的回应；
- **函数调用 (Tool Use)**：在接入 group_chat_plus 或支持 Agent 工具调用的会话中，LLM 在日常闲聊时可随时根据语境自主调用 `send_qq_like`。
